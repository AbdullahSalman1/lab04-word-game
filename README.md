# Hangman (Guess the Word) Game

## How to Run the Game

1. Make sure you have Python 3 installed.
2. Open a terminal in this project directory.
3. Run the following command:

```
python main.py
```

- The game will prompt you to guess letters until you win or run out of lives.

## How to Run the Tests

1. Ensure you are in the project directory.
2. Run the following command:

```
python tests.py
```

- This will execute the unit tests for the game logic and display the results.

---

If you have any issues, check that your Python installation is working and that you are in the correct directory.
